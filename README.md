# NUMPY-FUNDAMENTALS-END-TO-END-PROJECT

A practical Python project designed to strengthen my understanding and application of **NumPy fundamentals** for data analysis.

This project covers core NumPy operations, statistical calculations, array manipulation, Boolean filtering, and other techniques commonly used when working with numerical data in Python.

---

## Project Overview

NumPy (Numerical Python) is one of the fundamental libraries used in the Python data-analysis ecosystem.

The purpose of this project is to practice NumPy through hands-on exercises rather than only learning the syntax.

The project uses student score data to demonstrate how NumPy can be applied to:

- Create and manipulate numerical arrays
- Perform mathematical calculations
- Calculate descriptive statistics
- Filter data using Boolean conditions
- Work with percentiles and measures of dispersion
- Analyze numerical datasets

---

## Objectives

The main objectives of this project are to:

1. Understand NumPy arrays and their properties.
2. Perform numerical operations using NumPy.
3. Apply descriptive statistics to real numerical data.
4. Practice Boolean filtering.
5. Understand how NumPy can be used in data analysis.
6. Build a strong foundation for working with **Pandas, Matplotlib, and data science**.
